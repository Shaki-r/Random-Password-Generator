# 🔐 Random Password Generator

A modern and responsive **Random Password Generator** built using HTML, CSS, and JavaScript. This tool helps users generate random passwords with customizable length and character options.

## 🌐 Live Demo

👉 [View Random Password Generator](https://shaki-r.github.io/Random-Password-Generator/)

## ✨ Features

- Generate random passwords instantly.
- Customize password length using a range slider.
- Include uppercase letters (A–Z).
- Include lowercase letters (a–z).
- Include numbers (0–9).
- Include special symbols (!@#$).
- Copy generated passwords with one click.
- Password strength indicator.
- Modern and responsive user interface.
- Smooth animations and interactive elements.

## 🛠️ Technologies Used

- **HTML5** – Project structure.
- **CSS3** – Styling, animations, and responsive design.
- **JavaScript** – Password generation and functionality.
